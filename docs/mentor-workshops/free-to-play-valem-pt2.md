# Build the Essentials of a Free-to-Play App w/ ValemVR | F2P Academy Build-Along Part 2

In the second installment of ValemVR’s F2P Academy Build-Along series, you’ll dive deeper into the core challenge of multiplayer development: syncing data and interactions between players. This session walks you through transforming a single-player mini-golf prototype into a fully networked, turn-based experience using Unity’s Netcode for Game Objects and Meta’s SDK.

Recorded live in August 2025 as part of the Meta Horizon Start program.

💡 What You’ll Learn:

- The “Authority → Modify → Share” workflow
- When to use client vs. server authority
- How to implement synchronization in Unity
