# Build the Essentials of a Free-to-Play App w/ ValemVR | F2P Academy Build-Along Part 1

In the first installment of ValemVR’s F2P Academy Build-Along series, you’ll learn how to establish the foundation every great multiplayer project needs: getting two players reliably connected in the same shared space. This session walks you through the Meta Interaction SDK and Unity’s multiplayer tools, showing you how to build a quick prototype and understand the core systems that power real-time VR connections, By the end of this three-part series, you’ll know how to set up multiplayer essentials, in-app purchases (IAP), and more.

Recorded live in August 2025 as part of the Meta Horizon Start program.

💡 What You’ll Learn:

- Create a quick multiplayer prototype using Meta SDK Building Blocks
- Implement Unity Lobby, Relay, and Vivox for scalable room systems
- Reuse and customize the Unity VR Multiplayer Template
- Compare and test setups using Parallel Sync and Multiplayer Mode
