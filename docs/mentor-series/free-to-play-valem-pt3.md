# Build the Essentials of a Free-to-Play App w/ ValemVR | F2P Academy Build-Along Part 3

In the third and final installation of the Let’s Build a Free-to-Play Multiplayer VR Game series, you’ll learn how to integrate Meta’s core platform features into your Unity project. This session walks you through how to implement Avatars, In-App Purchases, and Leaderboards, then tackles the deeper challenge of keeping those systems synchronized across every player using Netcode for GameObjects.

Recorded live in August 2025 as part of the Meta Horizon Start program.
