# Getting Started with 2D Apps on Meta Quest | Let’s Learn

Ready to bring your Android and web apps to Meta Quest? In this Let’s Learn session from the Meta Horizon Start program, Abhijit Srikanth (Partner Engineer, Reality Labs) walks you through the full process, from setup to publishing, using real examples from the Meta engineering team.

Recorded live in February 2025 as part of the Meta Horizon Start program.

💡 What You’ll Learn:

- How to port Android apps to Meta Quest using Android Studio
- How to package web apps as PWAs with Bubblewrap
- How Meta Horizon OS enhances apps automatically (Theater View, Spatial Audio, Multitasking)
