# How to Design 2D Apps for Meta Quest | Let’s Learn

What if your mobile app could live in a 3D space with no Unity or Blender required? Meta product designers Chloe Xie and Rocco Rada show you how to adapt your 2D app for Meta Quest’s XR environment using the same 2D tools you already know. Learn how to design intuitive panel apps with responsive layouts, larger hit targets, and clear visual feedback. Plus — explore the “2.5D” design method to add depth and motion without full 3D complexity.

Recorded live in December 2024 as part of the Meta Horizon Start program. 

💡 What You’ll Learn:
- XR design primitives: geocentric vs allocentric panels
- Best practices for controllers, hand tracking, and voice input
- How to evolve mobile UI patterns for XR
- Techniques for testing and refining spatial interactions
