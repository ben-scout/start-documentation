# The New Meta Quest Runtime Optimizer Is Here

Meet the new Meta Quest Runtime Optimizer, a Unity-integrated profiling tool that shows you exactly what’s slowing down your app with no prerequisite GPU expertise required. In this Let’s Learn workshop, Meta Software Engineers Jay Hsia and Nico Lopez teach you how to pinpoint performance bottlenecks, measure GPU cost per game object, and make faster optimization decisions right inside the Unity Editor.

Recorded live in July 2025 as part of the Meta Horizon Start program.
