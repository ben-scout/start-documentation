# Unlock the New Passthrough Camera Access API

Get your first look at the Passthrough Camera Access API. Learn how to stream live camera data, integrate it with Unity, and explore new use cases in machine learning, computer vision, and advanced mixed reality graphics.

Recorded live in September 2025 as part of the Meta Horizon Start program.

💡 What You’ll Learn:

- How the Passthrough Camera Access API works and what’s supported
- How to use Unity’s WebCamTexture and Sentis for object detection
- Technical specs: 30 FPS, 40-60 ms latency, and 2-4% CPU overhead
- Rules of the public experimental release
- Privacy and permission best practices
