    Build a Free-to-Play Multiplayer VR Game - Tiny Golf

    Tiny Golf is a multiplayer VR mini-golf game built in Unity as part of a three-part live tutorial series by Quentin Valembois (Valem). Over about 5 hours of development, the series demonstrates how to implement key free-to-play multiplayer features using the Meta Quest Platform SDK and Unity’s Netcode for GameObjects.
